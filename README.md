# Baby panda hugging a sleeping chick

Entry for make.fun cutest-picture-01 (v4): a 3D-rendered fluffy baby giant
panda in close-up, huge round black-and-white face, enormous sparkling dark
eyes, head tilted, pink blushing cheeks, mint-green knitted scarf, gently
hugging a tiny fluffy yellow chick fast asleep with closed eyes.

Full-frame fix (2026-11-13): the first v4 image was cropped — the panda's
ears touched the top/left edges and its body was cut at the bottom. The
image was regenerated as a medium shot: the whole panda (both ears, both
paws, whole body and feet) and the whole chick are fully inside the frame
with clear cream background margin on all four sides, nothing touching or
crossing any edge. Face still large (~55-60% of frame height) with real
margins, like the top-5 entries.

The program simply copies `entry.png` to the output path, so both grader
runs write exactly the same bytes.

Run locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
